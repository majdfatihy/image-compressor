## 📖 نبذة عن المشروع (Overview)

تُعد سرعة تحميل الصفحات من أهم عوامل تصدر نتائج البحث (Technical SEO) وتقليل معدل الارتداد في مدونات بلوجر والمواقع الإلكترونية. صُممت **أداة ضغط وتصغير الصور** لتوفر حلاً عملياً وآمناً لتقليل حجم ملفات الصور الكبيرة مع الحفاظ على جودتها البصرية، وضبط مقاساتها بالبكسل قبل نشرها في المقالات، وكل ذلك يتم عبر معالجة محلية فورية (Client-Side Rendering) تضمن الخصوصية التامة للمستخدم.

---

## ✨ المميزات والخصائص التقنية (Key Features)

* 🔒 **خصوصية وأمان تام (100% Client-Side):** تتم جميع عمليات القراءة والضغط والتحويل داخل متصفح جهازك باستخدام `HTML5 Canvas` و `createImageBitmap` دون رفع أي صورة إلى خوادم خارجية.
* ⚖️ **مقارنة بصرية حية (Before / After Slider):** شريط تمرير تفاعلي لمعاينة ومقارنة دقة الصورة قبل وبعد الضغط لحظياً مع حساب نسبة التوفير في الحجم.
* 🎯 **الضغط الذكي حسب الحجم المستهدف (Target Size Compression):** ميزة البحث الثنائي التلقائي عن أفضل جودة ممكنة للوصول إلى حجم ملف محدد يختاره المستخدم بـ `KB` أو `MB`.
* 🔄 **دعم أحدث صيغ الويب:** استيراد وتصدير الصيغ القياسية والحديثة (`WebP`, `AVIF`, `JPEG`, `PNG`) مع وضع اختيار الصيغة التلقائي للأكثر كفاءة.
* 📐 **تحكم دقيق بالأبعاد (Custom Resizer):** تغيير عرض وارتفاع الصورة بالبكسل مع خيار قفل نسبة الأبعاد الأصلية (Aspect Ratio Lock) لمنع تشوه الصور.
* 📱 **توافق كامل مع الهواتف وتطبيقات Capacitor:** دعم الحفظ المباشر في التنزيلات على المتصفح، ودعم نظام الملفات والإشعارات المحلية (`Capacitor Filesystem & LocalNotifications`) عند تشغيل الأداة كتطبيق هاتف.
* 🌓 **الوضع الليلي والنهاري (Dark / Light Mode):** واجهة مريحة للعين تتكيف مع إعدادات النظام وتحفظ تفضيل الزائر في `localStorage`.
